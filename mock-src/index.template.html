ソケットモデル(アイテムタグとは独立)Socket model (independent from item tags)

  • Every socket declares a type (◆gem / ▷edge / ●coat / ▭bond) AND its own socket tags (e.g. Metal, Bone).
  • A Socket Item seats if: socket type matches its slot type, AND the socket carries all tags the Socket Item requires.
  • Examples here: Whetstone needs edge+Metal → fits Dagger/Blade, rejects Beast Jaw's edge(Bone). Arrowhead needs edge only → fits both. Poison Coat fits any coat socket — and coat sockets exist only on Weapons (the old type rule is now structural).
  • Item combat tags (Flame, Oil, Beast…) are a SEPARATE system used only for grid chemistry (adjacency combos).
