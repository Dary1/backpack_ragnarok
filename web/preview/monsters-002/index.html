The style is intentionally NOT unified yet — this is comparison material to pick the quality baseline. Generation uses a simple static 2D illustration pipeline only (no 3D conversion / rigging / animation).

#2方向の追加バリエーション(透過背景)#2 Direction — More Variations (transparent background)

背景はrembgによる自動セグメンテーションで透過化。カラーキー方式はマゼンタ/オレンジで背景色を変えて再テストしたが、「指定色が無視され元の背景に戻る」「指定色がキャラクター本体の肌に滲む」「構図自体が崩壊する」とテストごとに異なる形で破綻し不採用。生成モデル自体もtoonyou_beta6からDreamShaper_8・素のSD1.5に変えて再テストしたが、DreamShaperでも同様に背景色がキャラクター全体に滲み、素のSD1.5は指定を無視してフル背景シーンを描いてしまい、いずれも改善しなかった。この寒色パレットの氷モンスターに対して「背景だけ別色にする」という指示は、生成モデル側では安定して制御できないという結論。
一方、セグメンテーション側は改善の余地があった: 標準のU2Netモデルは氷の飛沫の縁が半透明の「ゴースト」状に残るだけでなく、足先の爪や細い氷の欠片など実際のキャラクター形状そのものを誤って削ってしまっていた(赤背景合成で確認)。イラスト特化のisnet-animeモデルに切り替えたところ、これらの部分が正しく保持されるようになったため、以後isnet-anime + alpha matting + マスク後処理を標準とする(下記カード参照)。カードの市松模様は透過部分の目安です。 Backgrounds removed via rembg automatic segmentation. Chroma-key was re-tested with two more background colors (magenta, orange) but broke down in a different way each time — the color was ignored and the old background came back, the color bled into the character's own skin, or the composition collapsed entirely. Also re-tested with two different generation checkpoints (DreamShaper_8, vanilla SD1.5) instead of toonyou_beta6 — DreamShaper bled the background color across the whole creature the same way, and vanilla SD1.5 ignored the flat-background instruction and rendered a full scene instead. Conclusion: for this creature's cool color palette, "isolate the background in a different color" isn't something the generation model can be reliably steered to do via prompting.
The segmentation side, on the other hand, had real room to improve: the default U2Net model wasn't just leaving soft "ghost" edges around fine details like ice-splash droplets, it was actually cutting away real character geometry — toe claws, thin ice-shard linework — as if it were background (confirmed by compositing onto solid red). Switching to isnet-anime, a segmentation model trained specifically on anime/illustration art, preserved that geometry correctly, so isnet-anime + alpha matting + mask post-processing is now the standard (see cards below). The checkered pattern marks the transparent area.

失敗した試行(参考)Failed Attempts (for reference)

同バッチで2件、ブリーフ(全身・正面)を満たさず除外: 肩に氷の棘を足した版はフレームアウトしてほぼ写らず、氷の冠を足した版は上半身のみのポートレートになった。
また透過方式としてカラーキー(クロマキー)を3パターン試して除外: (1)背景色を軽く指定 → 無視されて元の氷背景のまま、(2)背景色を強調して前方配置 → 背景色は変わったがキャラクターの肌・ハイライトに色が滲んだ、(3)氷色の補色(オレンジ)を選択 → 背景は綺麗な単色になったがキャラクターの構図自体が別物に崩れた。 Two more attempts in the same batch didn't meet the brief (full body, front-facing) and were excluded: the shoulder-spikes variant framed almost entirely out of shot, and the ice-crown variant came out as a bust/portrait instead of full body.
Also tried and dropped: 3 chroma-key (color-key) background attempts — (1) a light mention of the target color, which was ignored and the original icy background came back; (2) an emphasized color placed early in the prompt, which did change the background but bled into the character's own skin/highlights; (3) an orange background (chosen as the complementary color to the creature's icy palette), which came out as a clean flat color but collapsed the character's composition into a different, off-brief design.

多様なモンスター候補(氷にこだわらず・透過テスト)Diverse Monster Candidates (moving past ice, transparency test)

氷の霜/靄のような半透明表現が透過処理と根本的に相性が悪いのではという指摘を受け、氷から離れて8体(ゴブリン・オーク・スケルトン・ウルフ・ジャイアントスパイダー・リザードマン・マッシュルーム・ジャイアントバット)をシンプルな名称で生成。狙い通り、不透明な意匠のモンスターは透過の縁が大幅に安定した(isnet-anime + alpha matting + マスク後処理は据え置き)。ジャイアントスパイダーのみ2回とも「孤立したキャラクター」ではなく空・光条・岩壁を含む劇的な一枚絵になってしまい、透過処理がほぼ全消去という結果になったため除外(下記参照)。画風はまだ統一しておらず、これは「多様に出して良いものを選んでもらう」ための候補出しです。 On the hypothesis that ice/frost's inherently soft, misty, semi-transparent look was fundamentally at odds with clean background removal, we stepped away from ice and generated 8 simply-named monsters (goblin, orc, skeleton, wolf, giant spider, lizardman, mushroom, giant bat). As hoped, opaque-bodied designs segmented far more reliably (still isnet-anime + alpha matting + mask post-processing). Only the giant spider came back both times as a dramatic full scene (sky, light rays, rock walls) instead of an isolated character, so its background removal came back almost entirely empty and it's excluded below (see note). Style is intentionally not unified yet — this is a volume/variety pass so you can pick out the ones worth pursuing.

多様なモンスター候補 第2弾(見切れ対策・15体)Diverse Monster Candidates, Round 2 (anti-cropping fix, 15 monsters)

前回8体のうちskeletonのみ合格(理由: 見切れがない・画風も良い)、他は全て見切れが原因でNGとのフィードバックを受け、プロンプトに「全身が完全にフレーム内に収まる、余白を確保」を追加して15体を新規生成。結果: 見切れ自体は大きく改善したが、代わりに一部で新しい問題が出た — 「筋骨隆々の戦士」系の説明が、この checkpoint では劇的な一枚絵(空・岩・エネルギー効果込みの背景)を誘発しやすく、そのケースでは孤立キャラ向けのisnet-animeが背景を切り離せず、透過処理後も背景が残ったままになった(下記に⚠で明記)。skeletonのような比較的落ち着いた構図は今回も安定している。⚠の付いていないカードは見切れ・背景残りともに確認されていません。 From the first batch of 8, only skeleton passed (no cropping, and the style was liked); everything else was rejected for cropping. This round adds "entire body fully contained within frame, comfortable margin" to the prompt and generates 15 new monsters. Result: cropping is much improved, but a new issue showed up instead for some — descriptions like "muscular warrior" tend to push this checkpoint toward dramatic key-art compositions (sky, rock, energy-effect backgrounds), and in those cases isnet-anime couldn't isolate a background to remove, so the background survived transparency processing (flagged with ⚠ below). Calmer, skeleton-like compositions stayed reliable this round too. Cards without a ⚠ showed no cropping or background-removal issues in spot-checking.
