## Why
The synthesized click (REQ-0105) still did not fit. User asked for a refined
"gold latch" click as default plus an anvil option, and to add the anvil "as a
download" / a selectable SFX option in the styleguide.

## Note on "download"
Pulling arbitrary SFX off the web isn't available here (web tools return page
content, not usable binaries; the fetch restrictions forbid curl/wget fallbacks;
and random files carry licensing risk). Instead the assets are **generated
on-server via DSP modal synthesis** (`tools`-free, numpy) — license-clean, no
external dependency, tuned to the taste. If a specific recorded sample is wanted,
drop a WAV into `web/redesign/assets/` and it can be wired in.

## What changed
- New assets (modal synthesis = sum of exponentially-decaying inharmonic modes
  + a bright noise contact transient; generated by `outputs/gen_sfx2.py`):
  - `web/redesign/assets/sfx_latch.wav` — **上品なカチッ / gold latch** (0.10s,
    spectral centroid ~3.2kHz, bright & tight) — **default**.
  - `web/redesign/assets/sfx_anvil.wav` — **金床の一撃 / anvil clang** (0.60s,
    centroid ~0.59kHz, low & heavy with a long inharmonic ring).
- `clickSfx()` now plays the **selected WAV** via a decoded AudioBuffer
  (BufferSource → gain), falling back to the prior synth strike only if the clip
  can't load/decode. Clips are fetched+decoded once (`loadClips`), keyed by name.
- §6.7 adds a **click-sound picker** (`data-click="latch|anvil"`): selecting one
  sets `activeClick`, updates `.is-on`, and (being a normal click) auditions it.
  The choice drives every click across the page. Hover tick unchanged.

## Verification (headless, temp http server)
- Both WAVs served (200; 8,864 B / 52,964 B) and **decode in-page**
  (latch 0.100s, anvil 0.600s, mono).
- Picker toggles (`金床の一撃` → is-on; latch cleared). 0 console/page errors.
- Live serve confirmed on :8801 and the public tunnel.

## Follow-ups / tuning
- Timbres are fully tunable by re-running the generator (mode ratios, decays,
  f0, noise amount). E.g. latch brighter/softer, anvil heavier/longer.
- These SFX live in the styleguide only; wiring an interaction-sound layer into
  the shipped React client would be a separate REQ (needs settings + reduced-
  motion gating and a volume control).
