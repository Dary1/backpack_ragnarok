更新履歴 ・ Patch notes

プレイヤーから見える変更だけを載せています。不具合報告の際は、タイトル画面右下の build 番号を添えてください。
Only player-visible changes are listed here. When reporting a problem, please include the build id shown in the bottom-right corner of the title screen.

リリース磨き込み / Release polish

2026-08-11

  • タイトル画面に build 番号とこの更新履歴へのリンクを追加しました。 The title screen now shows a build id and links here.
  • 未実装の「フレンズ」をナビから一旦外しました。実装時に戻ります。 The unimplemented Friends rail entry is hidden until the feature ships.
  • 英語のナビ名を Backpacks から Squad に変更しました（日本語の「編成」はそのまま）。 The English rail label for the build hall is now “Squad”.
  • サインインのボタンが他の画面と同じ見た目になりました。 The sign-in buttons now use the same theme as the rest of the game.
  • 設定に UI の大きさ（小/中/大）を追加しました。 Settings gains a UI scale control (S / M / L).
  • 狭い画面で盤面を拡大できるズーム切替を追加しました。 A zoom toggle for the boards on narrow screens.
  • リプレイのシークバーをドラッグできるようになり、ログ行を押すとその時刻に飛べます。 Replay: drag the progress bar to scrub, and click a feed row to jump to that moment.
  • 設定からプロフィールの書き出しとアカウント削除ができるようになりました。 Settings gains a data export and an account deletion path.
  • 市場の価格欄に、直近の成約価格の推移を示すスパークラインを追加しました。 Market listings show a sparkline of recent settled prices.
